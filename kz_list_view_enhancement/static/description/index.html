List View Details

Make Odoo list views more flexible and informative

Enhance Odoo list views with expandable related records, selectable detail fields, and customizable column ordering. View related information directly from the list without repeatedly opening individual records. Built by Kogzio Solutions for Odoo Community and Enterprise.

Overview

List View Details improves the everyday Odoo list-view experience by bringing related information closer to the records users are already working with.

Users can expand a record to view related records, choose which detail fields are displayed, and rearrange list columns using drag and drop. Column preferences are stored per user and per list view, so different users can keep their own preferred layouts.

Key Features

  • Expandable Related Records — Expand a record to view its related records directly underneath it.
  • Works Across Related-Record List Views — Designed for applicable Odoo list views wherever the parent record has a related records list.
  • Dynamic Related-Record Detection — Automatically analyzes the form view associated with the current list view to identify applicable related-record fields, without requiring manual relationship configuration.
  • Selectable Detail Fields — Choose multiple fields to display inside the expanded related-record section.
  • Drag-and-Drop Column Swapping — Rearrange columns directly from Odoo list views.
  • User-Specific Column Order — Each user can maintain their own preferred column order.
  • List-View-Specific Preferences — A customized order is stored separately for each list view.
  • Persistent Preferences — Saved column arrangements remain available after refresh and subsequent login.

How It Works

  1. Open an applicable Odoo list view; the module dynamically identifies the related-record relationship from its associated form view.
  2. Use the expand control on a record to view its available related records directly underneath it in the list.
  3. Use the field selector inside the expanded section to choose the related fields you want to display.
  4. Drag and drop list columns to arrange them in your preferred order.
  5. The selected column order is saved for the current user and current list view.
  6. Return to the same list view later and your saved column arrangement is restored automatically.

Why Use List View Details?

  • Reduce the need to open records individually to inspect related information.
  • Keep important related details visible in context.
  • Choose only the related fields that matter to your workflow.
  • Personalize list-column layouts without changing the underlying Odoo view for other users.
  • Give different users independent list-view layouts based on their working preferences.

Technical Highlights

  • Generic Odoo list-renderer integration.

  • Related records are displayed directly in the list view when available for the parent record.
  • Related fields are derived from the applicable related-record list configuration.
  • User-specific and list-view-specific column preference storage.
  • Persistent column ordering across refreshes and subsequent logins.
